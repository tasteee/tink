# Held-back previews

These pages preview elements that are **not part of zest 1.0**: chat,
AI, attachments and the text-editor family. The source stays in
`src/components`, but the package entry does not export it (see
`scripts/held-back.mjs`).

- They are not published and not linked from the docs site.
- They are kept so work on those elements can resume after 1.0.
- Do not treat them as supported API.
